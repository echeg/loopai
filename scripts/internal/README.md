# Internal Scripts

Development and build utility scripts. Not intended for end users.

- **prep-toy-test.sh** - Creates a toy Go project at `/tmp/loopai-test` with buggy code and a plan file for end-to-end testing of loopai's full execution mode.
- **prep-review-test.sh** - Creates a toy Go project at `/tmp/loopai-review-test` with subtle code issues on a feature branch for testing review-only mode.
